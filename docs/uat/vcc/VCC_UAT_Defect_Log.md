# ทะเบียนบันทึกข้อบกพร่องการทดสอบระบบ VCC (VCC UAT Defect Log)

เอกสารฉบับนี้ใช้สำหรับบันทึก ติดตาม และคัดกรองข้อบกพร่อง (Defects) ที่ตรวจพบระหว่างการทดสอบรับมอบระบบ (UAT) และการประเมิน Audit Readiness ของระบบ VCC

---

## 1. เกณฑ์การจัดระดับความรุนแรงของข้อบกพร่อง (Severity Classification)

| ระดับความรุนแรง | นิยามและผลกระทบ | เกณฑ์ต่อการตัดสินใจ Go/No-Go |
| :---: | :--- | :--- |
| **Blocker (ระดับ 1)** | ส่งผลให้ระบบล่ม ข้อมูลสูญหาย สิทธิ์ความปลอดภัยรั่วไหล (เช่น การทะลุสิทธิ์ข้ามแผนก, ตนเองอนุมัติตนเองได้) หรือไม่สามารถดำเนินการต่อได้ | **ต้องเป็น 0 เท่านั้น** หากพบต้องระงับการรับมอบทันที |
| **Critical (ระดับ 2)** | กระบวนการหลักตามข้อกำหนดมาตรฐานล้มเหลว (เช่น ไม่สามารถสร้าง Snapshot, ไม่สามารถบันทึก Audit Log, ปลดระงับไม่ได้) โดยไม่มีขั้นตอนชั่วคราวทดแทน | **ต้องเป็น 0 เท่านั้น** ก่อนการลงนามรับมอบระบบ |
| **Major (ระดับ 3)** | ส่งผลต่อการทำงานสำคัญบางส่วน แต่ยังมีกระบวนการทำงานทดแทนชั่วคราวได้ (Workaround) หรือการแสดงผลบนอุปกรณ์เฉพาะมีปัญหา | ต้องได้รับการประเมินความเสี่ยงและกำหนดแผนแก้ไขก่อนส่งมอบ |
| **Minor / Trivial (ระดับ 4)** | ข้อบกพร่องด้านความสวยงาม (Cosmetic), การจัดช่องว่าง UI เล็กน้อย หรือคำสะกดผิดที่ไม่กระทบต่อความหมายทางมาตรวิทยา | สามารถยอมรับให้ดำเนินการแก้ไขในรอบบำรุงรักษาถัดไปได้ |
