# ข้อมูลจำลองสำหรับทดสอบระบบ VCC (VCC UAT Test Data Guide)

เอกสารฉบับนี้รวบรวมรายการข้อมูลจำลอง (Synthetic Test Data) สำหรับใช้ในกระบวนการทดสอบรับมอบระบบ (UAT) และการประเมิน Audit Readiness ของโมดูล VCC เพื่อให้การทดสอบเป็นไปอย่างรัดกุม ทำซ้ำได้ และไม่ปะปนกับข้อมูลจริงในสภาพแวดล้อม Production

---

## 2. ข้อมูลเครื่องมือสำหรับสร้างใหม่ระหว่าง UAT (Dynamic Test Data)

รายการข้อมูลที่ผู้ทดสอบจะทำการคีย์เข้าระบบผ่านหน้าจอผู้ใช้ในระหว่างรันกรณีทดสอบ `VCC-UAT-001`:

1. **เครื่องมือวัดเดี่ยว (Individual Asset):**
   - รหัสเครื่องมือ: `VM-001`
   - ชื่อเครื่องมือ: `[ข้อมูลทดสอบ] ดิจิทัลมัลติมิเตอร์ Fluke 87V`
   - ประเภท: `มัลติมิเตอร์ (Multimeter)`
   - รุ่น / ยี่ห้อ: `Fluke 87V`
   - หมายเลขซีเรียล: `SN-FLK-87V-9921`
   - สถานที่ติดตั้ง / เก็บรักษา: `ห้องสอบเทียบเครื่องมือวัดชั้น 2`
   - แผนกเจ้าของ: `QC`
   - ขีดจำกัดความคลาดเคลื่อนที่ยอมรับได้ (MPE): `±0.05% of reading`
   - ช่วงการวัด (Range): `0.1 mV - 1000 V`
   - ความถี่การสอบเทียบ: `12 เดือน`

2. **เครื่องมือวัดชุดรวม (Composite Set Asset):**
   - รหัสเครื่องมือ: `GB-SET-01`
   - ชื่อเครื่องมือ: `[ข้อมูลทดสอบ] ชุดเกจบล็อกมาตรฐาน (Gauge Block Set 83 ชิ้น)`
   - ประเภท: `เกจบล็อก (Gauge Block)`
   - รุ่น / ยี่ห้อ: `Mitutoyo Grade 1`
   - หมายเลขซีเรียล: `SN-GB-83PCS-001`
   - สถานที่ติดตั้ง / เก็บรักษา: `ตู้เก็บเครื่องมือมาตรฐานควบคุมอุณหภูมิ 20°C`
   - แผนกเจ้าของ: `QC`
   - ลักษณะกลุ่ม: `COMPOSITE_SET (ชุดรวมที่ไม่แยกสอบเทียบ)`

## 3. ข้อมูลชุดจำลองใบสั่งงาน (Work Order Test Data Suites)

### 3.1 ชุดข้อมูลผลการสอบเทียบผ่านเกณฑ์ (PASS Scenario)
- **เครื่องมือวัด:** `ST002`
- **ประเภทงาน:** ตามแผนประจำปี (Planned)
- **วันที่สอบเทียบ:** วันที่ปัจจุบัน
- **สถาบันที่ทำการสอบเทียบ:** สถาบันมาตรวิทยาแห่งชาติ (มว.) / NIMT
- **เลขที่ใบรับรอง (Certificate No.):** `CERT-2026-NIMT-9812`
- **ผลการสอบเทียบ (Result):** `PASS`
- **ค่าความคลาดเคลื่อนสูงสุด (Max Error):** `+0.02 °C` (MPE = `±0.10 °C`)
- **ค่าความไม่แน่นอนในการวัด (Uncertainty $U$):** `±0.01 °C` (Coverage Factor $k = 2$, ระดับความเชื่อมั่น 95%)
- **การแนบไฟล์:** แนบไฟล์ `sample_calibration_cert.pdf`
- **ผลลัพธ์ที่คาดหมาย:** สถานะเครื่องมือคงเป็น `ACTIVE`

### 3.2 ชุดข้อมูลผลการสอบเทียบไม่ผ่านเกณฑ์ (FAIL / ON_HOLD Scenario)
- **เครื่องมือวัด:** `TC001`
- **ประเภทงาน:** นอกแผนเร่งด่วน (Ad-hoc)
- **วันที่สอบเทียบ:** วันที่ปัจจุบัน
- **สถาบันที่ทำการสอบเทียบ:** ศูนย์สอบเทียบเครื่องมืออุณหภูมิภายนอก
- **เลขที่ใบรับรอง (Certificate No.):** `CERT-2026-EXT-4401`
- **ผลการสอบเทียบ (Result):** `FAIL`
- **ค่าความคลาดเคลื่อนสูงสุด (Max Error):** `+1.85 °C` (MPE = `±0.50 °C`) — *เกินเกณฑ์ที่ยอมรับได้*
- **ผลลัพธ์ที่คาดหมาย:** เมื่อ `qc6` ตรวจรับผล เครื่องมือจะถูกปรับเป็น **`ON_HOLD`** ทันที

### 3.3 ชุดข้อมูลการขอปลดระงับเครื่องมือ (Release Hold Data)
- **ใบสั่งงาน:** ใบสั่งงานของ `TC001` จากข้อ 3.2
- **ผู้ดำเนินการ:** ผู้จัดการฝ่าย QC (`qc6`, L6)
- **เหตุผลการปลดระงับ (`release_reason`):**  
  `[ข้อมูลทดสอบ] ส่งอุปกรณ์เข้าศูนย์บริการเพื่อเปลี่ยน Sensor Probe และ Calibrate ซ้ำ ผลการวัดรอบสองผ่านเกณฑ์ MPE เรียบร้อยแล้ว`
- **การประเมินผลกระทบต่อคุณภาพผลิตภัณฑ์ (`impact_assessment`):**  
  `[ข้อมูลทดสอบ] ตรวจสอบย้อนกลับประวัติอุณหภูมิห้องเย็น F1 ย้อนหลัง 7 วันที่ผ่านมา อุณหภูมิเฉลี่ยอยู่ที่ -18.2 °C ถึง -19.0 °C ซึ่งอยู่ในช่วงควบคุม (-18 ± 2 °C) ผลิตภัณฑ์ทั้งหมดไม่ได้รับผลกระทบต่อความปลอดภัยและคุณภาพ (Acceptable Risk - No Product Impact)`
