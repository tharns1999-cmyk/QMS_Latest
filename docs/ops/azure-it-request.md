# ข้อความขอความช่วยเหลือจาก IT (ร่างสำหรับส่ง)

เรียน ทีม IT

ระบบ QMS Portal เสร็จพร้อมย้ายไปใช้บน Microsoft Azure แล้ว (โค้ดทดสอบบนเครื่องผู้พัฒนาผ่านครบ ยังไม่เคยขึ้น Azure จริง) ขอความช่วยเหลือให้ตั้งค่าฝั่ง Azure/Microsoft 365 ตามเอกสารแนบ เริ่มจากสภาพแวดล้อมทดสอบ (UAT) ก่อน

## สิ่งที่ขอให้ IT ดำเนินการ
1. **ให้ Azure subscription** และสร้าง App Service (Linux, Node 24), Azure Database for PostgreSQL และ Storage account (Blob) ภูมิภาคเดียวกัน กรุณายืนยันกับบริษัทว่าเก็บข้อมูลคุณภาพนอกประเทศได้หรือไม่ก่อนเลือกภูมิภาค
2. **สร้างฐานข้อมูลให้ถูกชนิด** (`LC_COLLATE C`, UTF8) และเปิดส่วนเสริม `CITEXT` ถ้า Azure ไม่อนุญาตให้ระบุ `LC_COLLATE C` กรุณาแจ้งกลับทันที
3. **ลงทะเบียนแอปใน Entra ID** เพื่อให้ผู้ใช้ล็อกอินด้วยบัญชี Microsoft ของบริษัท แล้วส่งค่า Tenant ID, Client ID, Client secret ให้ผ่านช่องทางที่ปลอดภัย (ไม่ส่งในแชต) พร้อมแจ้งวันหมดอายุของ secret
4. **ให้ Managed Identity ของ App Service มีสิทธิ์ Storage Blob Data Contributor** บน Storage account
5. **แจ้งที่อยู่เว็บ** ที่ผู้ใช้จะเปิด และชื่อ App Service
6. **ตั้งค่าให้ GitHub ส่งงานขึ้น Azure** (OIDC) และตั้ง Application settings ตามตารางในเอกสาร
7. **เปิดการสำรองอัตโนมัติและ point-in-time restore** และช่วยซ้อมกู้คืนจริง 1 ครั้ง เพื่อเก็บเป็นหลักฐานสำหรับผู้ตรวจ ISO

ไม่ต้องติดตั้ง Docker และไม่ต้องมี Container Registry

## เอกสารแนบ (ในโฟลเดอร์ docs/ops)
- `azure-app-deploy.md` : สร้างอะไร ตั้งค่าอะไร ขึ้นแอปอย่างไร
- `azure-database-setup.md` : ตั้งค่าฐานข้อมูล
- `azure-entra-signin.md` : ล็อกอินด้วยบัญชี Microsoft
- `azure-uat-checklist.md` : รายการตรวจตอนขึ้นทดสอบ

## ฝั่งบริษัทจะดำเนินการเอง
- DCC ตรวจอีเมลของผู้ใช้ทุกคนในระบบให้ตรงกับอีเมลล็อกอิน Microsoft 365
- ผู้ใช้จริงร่วมทดสอบล็อกอินตามสิทธิ์

เมื่อได้ที่อยู่เว็บและค่าต่างๆ แล้ว ผู้พัฒนาจะดำเนินการส่งงานขึ้นทดสอบและรายงานผล
